# Autopilot Troubleshooting

## Registration

Check whether the device is correctly registered and targeted by the intended deployment profile.

## Enrollment

Validate:

- network connectivity
- Entra join
- Intune enrollment
- licensing
- device restrictions

## Enrollment Status Page

Identify whether the failure is associated with:

- security policy
- device configuration
- application installation
- timeout
- reboot requirements

## Required applications

A single blocking application can prevent the user reaching the desktop. Check detection rules, dependencies, install context and return codes.

## Operational principle

Capture the failure stage and recurring patterns so build issues become engineering/problem-management work rather than repeated one-off support.
